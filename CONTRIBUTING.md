# Contributing

Contributions are welcome through issues and pull requests.

- Do not commit local `V100Monitor.ini`, logs or telemetry CSV files.
- Remove GPU UUIDs, serial numbers, usernames and local paths from reports.
- Keep the monitor dependency-free and compatible with the Windows .NET Framework compiler.
- Test that one or more selected GPUs render without overlapping text or borders.
- Keep vendor access read-only and do not include kernel drivers.

By contributing, you agree that your changes are licensed under the MIT License.
